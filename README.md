SnakeGame-Game
==============

A copy of the popular arcade game "Snake" - Using Python (tkinter)

Instructions: 
-------------
  + Use the "W-A-S-D" keys to move around.
  + Press "Enter" or "Return" to restart once the game is over.

⚠️
Warning: 
--------
Do not edit the highscore.txt file.
